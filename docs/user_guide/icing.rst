结冰
====

等压面上的结冰类别来自 ``AVIATION.f`` 的 ``CALICING``。``MDL2P.f`` 可用场 257，短名 TIPD。值为 1 或 0。

三个条件同时成立才是 1：

- 温度在 251 K 到 273 K，含两端
- 相对湿度不低于 70%
- omega 小于 0（Pa s\ :sup:`−1`，上升）

``CALICING`` 的注释写相对湿度是小数。``MDL2P.f`` 传进去的 ``SAVRH`` 是 ``CALRH`` 的结果再乘 100，阈值 70 对的是百分数。

注释里还写了相当位涡和过冷大滴。子程序没有用这两项。

``GFIP3.f`` 的 ``icing_algo``（可用场 450 和 480）是 NCAR 的另一套柱算法。``MDLFLD.f`` 里等压面 GRIB 写出那段是注释掉的。这里不移植 GFIP。
